## The result that changed shape

WT-030 claimed a stock levy opposes the multiplicative term and a flow levy does not,
*regardless of rate*. The sweep says: right about the direction, wrong about "regardless".

- At a matched rate the two bases are ~an order of magnitude apart, every rate tested.
- Mechanism: `kappa`, the share of aggregate wealth moved per assessment. Stock: `kappa = rate`
  exactly. Flow: `rate * E[eta+] = rate * 0.1073`, closed form
  `mu*Phi(mu/sigma) + sigma*phi(mu/sigma)`, asserted in the suite.
- But a **fully realised** flow levy does bound the Gini. Reachable frontiers are nested
  (stock 0.000 < flow 0.125), not disjoint.
- The surviving, sharper claim is **realisation**: at `rho = 0` a **100% flow levy is
  statistically indistinguishable from no levy at all** (Gini 0.994 vs 0.994, top decile 1.000
  in both). That is the true "regardless of rate" result, and it is a statement about what a
  base can *observe*.

Manuscript sentence replaced to match. The temptation to define "flow" so the original claim
came out right was noted and refused — that is the WT-002 / WT-016 trap wearing a new hat.

## Tooling fixed along the way

- **`scripts/handoff_gate.py`** — `--emit` blessed a handoff carrying `gh_sha: PENDING` and
  printed "sha matches HEAD". `sh()` swallows git's stderr, so `git diff PENDING..HEAD` failing
  looked exactly like "nothing changed". The guard built to catch stale handoffs was blind to
  the most obvious stale handoff there is. Exit codes are now tri-state (0 / 1 blocker /
  **2 cannot verify, not a pass**); all three paths exercised. Commit `ff763b4`.
- **`gate-selfcheck.sh` range-ref detector** — broken by two-letter gate steps in both
  directions: `^## G-[A-Z]` read `G-AB` as `G-A` so the ceiling came out Z, and `endp` took the
  last letter so a *correct* `G-A→G-AA` reference fired a spurious warning. Fixed with an
  ordinal rank (`AB` = 28 > `Z` = 26). With the ceiling correct it immediately surfaced **four
  genuinely stale range references** the broken version had been hiding. All four fixed, and the
  n8n runtime box redeployed to match. `darwin-mac-ops` `ccd9ca1`.
