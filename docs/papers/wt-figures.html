Wealth Tensor: the figures

Nine figures across two papers, drawn in one visual language so a decision about any one of them is a decision about all of them.

Jason C. Braatz · drafts v1.0 · 26 August 2026

What this page is for. These nine figures carry both papers' arguments end to end. Every one is drawn from the same palette, the same mark specs and the same grid weight, so that a decision made here about one chart is a decision about all of them. Each figure's eyebrow names the section it belongs in. Hover any mark for its value; every figure carries its own data table. Nothing here is final — the point is to have something specific enough to disagree with.

Visual language, stated once so it can be argued with. Two categorical hues only (blue #2a78d6, orange #eb6834), assigned by role and never cycled; asset-class tiers use an ordinal blue ramp because a ladder is not four categories. One y-axis per panel, always — where two quantities have different scales they get two panels, never two axes. Grid and axes recessive; direct labels on endpoints rather than a number on every mark; a legend only where there are two or more series. Colorblind separation was computed rather than judged: every palette on this page passes the lightness-band, chroma-floor, CVD-separation, normal-vision and contrast checks against the actual surfaces used, in both light and dark mode. Dark mode is a selected set of steps, not an inverted one. The neutrals carry a slight bias toward the accent hue rather than sitting on pure grey.
